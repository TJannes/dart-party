# Animation ideas

What is agreed about animations is in `PLAN.md` under "Animations", with the
build steps 6, 8 and 9. This file only keeps ideas that are not yet decided.

## Themed moments

The ideas per game are agreed and built for all eleven games; they are in
`PLAN.md` under "Animations" now.

Knockout idea, not agreed: the "Final duel" banner of Last One Standing
could also play in Higher or Lower and Time Bomb.

**Draw, standings, deciding round**
- Draw: the chosen game bursts out of the reel with its own icon.
- Deciding round: "Sudden death" curtain, the tied avatars face each other.

## General moments, as a starting point for step 6

| Moment | Idea |
| --- | --- |
| Dart lands | Impact ring and a little shake on the board at the exact spot; the value flies from the dart to the player's score. |
| Good dart | Avatar hops, sparkles in the player's colour. |
| Great dart | Scene flashes, avatar cheers, confetti burst from the avatar. |
| Bad dart / miss | Avatar sulks, a small grey cloud above it, the dart "boings" off the edge. |
| Attack | Something flies from the attacker's avatar to the victim's avatar; the victim flinches. |
| Life lost | A heart cracks and falls off the player's card. Last life: the heart pulses beforehand. |
| Knocked out | Avatar turns grey, spins and drops off the screen, or gets a ghost that floats up. |
| Turn change | The next avatar slides to the oche under a spotlight; name banner sweeps in. |
| Game won | Winner's avatar grows to the centre, confetti cannon, the others clap or sulk. |
| Points handed out | Points fly as coins into the scoreboard rows; rows swap places with a slide. |
| Podium | Avatars climb their step one by one, third first; fireworks for the winner. |
| Three in one segment | "Hat-trick!" banner. |
| Bullseye | The board pulses outward like a gong. |
| Triple 20 / 180 | Fireworks, the lights of the game-show frame chase. |
| Three misses in one turn | Tumbleweed rolls past, a cricket chirps. |
| Decided on the last dart | Slow-motion zoom on that dart. |
